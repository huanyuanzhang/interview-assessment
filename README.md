## frontend
# 电商商品详情页（PDP）

## 技术栈

- React 18
- TypeScript
- Vite
- Jest + React Testing Library
- CSS Modules
- react-hot-toast

## quick start

### dependence

```bash
npm install
```

### dev mode

```bash
npm run dev
```

### pro mode

```bash
npm run build
npm run preview
```

### test mode

```bash
npm test
npm run test:watch
```

## structure

```
ecommerce-pdp/
├── public/                 # 静态资源
├── src/
│   ├── components/         # 可复用组件
│   ├── pages/             # 页面组件
│   ├── services/          # API服务
│   ├── hooks/             # 自定义hooks
│   ├── types/             # TypeScript类型
│   ├── utils/             # 工具函数
│   └── styles/            # 样式文件
├── tests/                 # 测试文件
└── package.json
```
